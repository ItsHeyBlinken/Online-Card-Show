# Online Card Show

**Live site:** https://onlinecardshow.com

Online Card Show is an online marketplace for trading card sellers and buyers, built as a 24/7 virtual card show. Collectors can browse seller storefronts, search listings, and connect with sellers anytime, without waiting for an in-person show.

## What it does

- **Seller storefronts:** each seller gets their own storefront for listing cards.
- **Browse by category:** sports cards (baseball, basketball, football, hockey, soccer) and trading card games such as Pokémon, Magic: The Gathering, and Yu-Gi-Oh!.
- **Search and filtering** to find specific cards.
- **Secure payments** powered by Stripe.

## Tech stack

Online Card Show is a PERN application:

- **PostgreSQL** for the database
- **Express** for the REST API
- **React** for the front end
- **Node.js** for the server runtime

## About this repository

The application source code is kept in a private repository because Online Card Show is a live production app.
